# Azure Landing Zones

## Definition

Azure Landing Zones provide a governed, secure, and scalable Azure environment.

## Components

- Management Groups
- Subscriptions
- Resource Groups
- RBAC
- Azure Policy
- Networking
- Monitoring

## Purpose

Provide a standardized platform for teams to deploy workloads.

## Benefits

- Governance
- Security
- Consistency
- Scalability
- Cost Management

## Architect Thinking

A Landing Zone is prepared before application teams deploy resources.
