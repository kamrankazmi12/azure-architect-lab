# Basic Azure Landing Zone

## Goal

Provide a secure and governed Azure platform for application teams.

## Structure

Tenant
│
└── Management Group
    │
    ├── Production Subscription
    ├── Development Subscription
    └── Shared Services Subscription

## Governance

- Azure Policy
- RBAC
- Standardized naming
- Required tags

## Benefits

- Security
- Governance
- Scalability
- Consistency

## Architect Note

Application teams consume the platform.
Platform teams govern the platform.
